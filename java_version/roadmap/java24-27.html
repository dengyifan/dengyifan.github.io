24.1 Primitive Types in Patterns, instanceof, and switch（JEP 488 · 预览）

⚠️ 需 --enable-preview --release 25。24 时点为第二次预览（JEP 488），25 上为第三次预览（JEP 507），26/27 分别是第四（JEP 530）、第五次（JEP 532）。本机没有 JDK 24，下面按 25 现行预览形态实测：

public class Prim24 {
  public static void main(String[] a) {
    Object o = 42;
    if (o instanceof int i) System.out.println("prim " + i);
    Object s = "hi";
    if (s instanceof int j) System.out.println("never " + j); else System.out.println("not prim");
  }
}
// 运行输出：
// prim 42
// not prim

✅ 实测（JDK 25 + 预览开关；javac 会提示「使用 Java SE 25 的预览功能」，属正常）。要点：Object 里的装箱值可用 instanceof int 拆箱绑定成基元模式变量，不匹配则不进分支。⚠️ 25 上 switch 的布尔选择器写法 case true / case false 同属基元模式、也要 preview，本页不采用。

24.2 Flexible Constructor Bodies（JEP 492 · 第三次预览 → JDK 25 转正）

✅ 实测（JDK 25）：JEP 513 已在 25 转正，免预览开关；24 时点是第三次预览，需 --enable-preview --release 24（本机无法运行）。

class FlexBase {
  FlexBase(int x) { System.out.println("base " + x); }
}
public class Flex24 extends FlexBase {
  Flex24() {
    System.out.println("stmts");
    super(9);
  }
  public static void main(String[] a) {
    new Flex24();
  }
}
// 运行输出：
// stmts
// base 9

✅ 实测（JDK 25）。要点：JEP 492 之前 super(...) 之前只允许「简单表达式」（读 final 字段、调用静态方法），现在可以先执行任意语句再调 super——先校验、先算，最后才把结果交给父类构造器。

24.5 Stream Gatherers（JEP 485 · 正式）

import java.util.stream.Gatherers;
import java.util.stream.IntStream;
public class Gather24 {
  public static void main(String[] a) {
    var windows = java.util.stream.Stream.of(1, 2, 3, 4, 5)
        .gather(Gatherers.windowFixed(2)).toList();
    System.out.println(windows);
    var sums = IntStream.range(0, 5).boxed()
        .gather(Gatherers.scan(() -> 0, Integer::sum)).toList();
    System.out.println(sums);
  }
}
// 运行输出：
// [[1, 2], [3, 4], [5]]
// [0, 1, 3, 6, 10]

✅ 实测（JDK 25）。要点：gather 是继 map/flatMap/collect 之后的中间操作扩展点，Gatherer 接口可自定义「元素 → 0..n 个输出」的有状态流水；内置 windowFixed/windowSliding/fold/scan/mapConcurrent（javap java.util.stream.Gatherers 核对）。windowFixed(2) 尾部不足一批也照发（[5]）。22/23 两轮预览（JEP 461/473）后于 24 转正。

24.6 Class-File API（JEP 484 · 正式）

import java.lang.classfile.ClassFile;
import java.lang.classfile.ClassModel;
public class ClassFile24 {
  public static void main(String[] a) throws Exception {
    byte[] bytes;
    try (var in = ClassFile24.class.getResourceAsStream("ClassFile24.class")) {
      bytes = in.readAllBytes();
    }
    ClassModel model = ClassFile.of().parse(bytes);
    System.out.println("thisClass=" + model.thisClass().asSymbol());
    System.out.println("major=" + model.majorVersion() + " methods=" + model.methods().size());
    System.out.println("names=" + model.methods().stream().map(m -> m.methodName().stringValue()).toList());
  }
}
// 运行输出：
// thisClass=ClassOrInterfaceDesc[ClassFile24]
// major=69 methods=3
// names=[<init>, main, lambda$main$0]

✅ 实测（JDK 25）。要点：ClassFile.of().parse(byte[]) 得到 ClassModel（常量池、访问标志、字段、方法），build(ClassDesc, Consumer) 生成字节码，transformClass 读改写——JDK 内部 ASM 的公开替代品（22/23 两轮预览 JEP 457/466 后于 24 转正）。major=69 即 class 文件版本 69（Java 25）；方法数 3 = <init> + main + 编译器生成的 lambda 桥。

24.7 Scoped Values（JEP 487 · 第四次预览 → JDK 25 转正）

✅ 实测（JDK 25）：JEP 506 已转正，免预览；24 时点是第四次预览（素材写「第二次」，见本节勘误注）。

import java.lang.ScopedValue;
public class Scoped24 {
  static final ScopedValue<String> WHO = ScopedValue.newInstance();
  public static void main(String[] a) {
    ScopedValue.where(WHO, "alice").run(() ->
        ScopedValue.where(WHO, "bob").run(() ->
            System.out.println("nested " + WHO.get())));
    ScopedValue.where(WHO, "carol").run(() -> System.out.println("in " + WHO.get()));
    System.out.println("bound inside=" + ScopedValue.where(WHO, "dave").call(() -> WHO.isBound()));
    System.out.println("outside bound=" + WHO.isBound());
  }
}
// 运行输出：
// nested bob
// in carol
// bound inside=true
// outside bound=false

✅ 实测（JDK 25）。要点：where(K,V).run/call(...) 的绑定只在该动态作用域内可见（内层覆盖外层），作用域外 isBound()=false、get() 抛 NoSuchElementException（见 25.2）；不可变、随线程创建/继承传递，专为「请求上下文、事务 ID」这类只读传递数据设计（对比 ThreadLocal：可变、有泄漏与装箱成本）。

24.8 后量子密码：ML-KEM + ML-DSA（JEP 496 / JEP 497 · 正式）

import java.security.KeyPairGenerator;
import java.security.Signature;
import java.util.Arrays;
import javax.crypto.KEM;
public class PQC24 {
  public static void main(String[] a) throws Exception {
    var kp = KeyPairGenerator.getInstance("ML-DSA").generateKeyPair();
    var signer = Signature.getInstance("ML-DSA");
    signer.initSign(kp.getPrivate());
    signer.update("post-quantum".getBytes());
    byte[] sig = signer.sign();
    signer.initVerify(kp.getPublic());
    signer.update("post-quantum".getBytes());
    System.out.println("ML-DSA verify=" + signer.verify(sig) + " sigLen=" + sig.length);

    var kem = KEM.getInstance("ML-KEM");
    var recv = KeyPairGenerator.getInstance("ML-KEM").generateKeyPair();
    var enc = kem.newEncapsulator(recv.getPublic()).encapsulate();
    var dec = kem.newDecapsulator(recv.getPrivate()).decapsulate(enc.encapsulation());
    System.out.println("ML-KEM encap=" + enc.encapsulation().length
        + " sharedMatch=" + Arrays.equals(enc.key().getEncoded(), dec.getEncoded()));
  }
}
// 运行输出：
// ML-DSA verify=true sigLen=3309
// ML-KEM encap=1088 sharedMatch=true

✅ 实测（JDK 25，免预览）。要点：JDK 24 同时交付 JEP 496（ML-KEM 密钥封装）与 JEP 497（ML-DSA 签名）——KEM 抽象（newEncapsulator/newDecapsulator/encapsulate/decapsulate），KeyPairGenerator/Signature 直接按算法名取用；ML-DSA-65 默认签名 3309 字节（远大于 ECDSA 的 ~64B）。⚠️ 本机探测：SLH-DSA、HQC 的 KeyPairGenerator.getInstance 抛「not available」，25 上不可用。素材把「ML-DSA 正式」记在 26，实际 24 就已交付（见 26.7）。

25.1 Primitive Types in Patterns, instanceof, and switch（JEP 507 · 第三次预览）

⚠️ 需 --enable-preview --release 25。轮次：JEP 455（23 首次）→ 488（24 第二次）→ 507（25 第三次，与 24 无改动）→ 530（26 第四次，收紧 dominance/无条件精确性判定）→ 532（27 第五次）。

public class PrimSw {
  public static void main(String[] a) {
    Object o = 3;
    String r = switch (o) {
      case int i when i % 2 == 0 -> "even " + i;
      case int i -> "odd " + i;
      default -> "?";
    };
    System.out.println(r);
    Object n = 7;
    if (n instanceof int v && v > 5) System.out.println("big " + v);
  }
}
// 运行输出：
// odd 3
// big 7

✅ 实测（JDK 25 + 预览开关；编译器提示「使用 Java SE 25 的预览功能」属正常）。要点：① switch 可用基元类型模式 case int i 并带 when 守卫，对 Object 选择器装箱值拆箱匹配；② instanceof int v 之后 v 可在 && 后续条件里直接用。布尔选择器 switch (b) { case true ... case false ... } 同属本特性（25 起合法写法，同样要 preview），本页未采用。

25.2 Scoped Values（JEP 506 · 正式）

✅ 实测（JDK 25，免预览）。转正历程：21 首次预览（JEP 446）→ 24 第四次预览（JEP 487）→ 25 转正（JEP 506）。

import java.lang.ScopedValue;
public class Scoped25 {
  static final ScopedValue<String> REQ = ScopedValue.newInstance();
  public static void main(String[] a) throws Exception {
    String out = ScopedValue.where(REQ, "req-42").call(() -> "handle " + REQ.get());
    System.out.println(out);
    try { System.out.println(REQ.get()); }
    catch (java.util.NoSuchElementException e) { System.out.println("outside: " + e.getMessage()); }
  }
}
// 运行输出：
// handle req-42
// outside: ScopedValue not bound

✅ 实测（JDK 25）。要点：where(K,V).call(...) 返回绑定作用域内的计算结果；作用域外 get() 抛 NoSuchElementException，消息 ScopedValue not bound。与 ThreadLocal 的差异见 24.7。

25.3 Stable Values（JEP 502 · 第一次预览）

⚠️ 需 --enable-preview --release 25。25 时点类型名是 java.lang.StableValue（本机 javap java.lang.StableValue 核对；java.lang.LazyConstant 在 25 不存在）。

import java.lang.StableValue;
public class SV25b {
  static final StableValue<Integer> ANSWER = StableValue.of();
  public static void main(String[] a) {
    System.out.println(ANSWER.orElseSet(() -> 42));
    System.out.println(ANSWER.orElse(-1) + " set=" + ANSWER.isSet());
  }
}
// 运行输出：
// 42
// 42 set=true

✅ 实测（JDK 25 + 预览开关）。要点：of() 创建未初始化常量；首次 orElseSet(计算) 求值一次并记住，之后 orElse(-1) 直接返回已记住的 42（isSet()=true），「延迟初始化 + 至多一次 + 可常量折叠」。后续轮次（按 JEP 531 历史注）：26（JEP 526）更名 LazyConstant、把 List.ofLazy/Map.ofLazy 放进 java.util.List/Map 接口、删除 orElseSet/setOrThrow/trySet；27（JEP 531）再删 isInitialized/orElse、新增 Set.ofLazy。

25.4 Key Derivation Function API（JEP 510 · 正式）

import java.nio.charset.StandardCharsets;
import java.util.Arrays;
import javax.crypto.KDF;
import javax.crypto.spec.HKDFParameterSpec;
import javax.crypto.spec.SecretKeySpec;
public class KDF25 {
  public static void main(String[] a) throws Exception {
    var kdf = KDF.getInstance("HKDF-SHA256");
    byte[] key = "master-secret".getBytes(StandardCharsets.UTF_8);
    byte[] prk = kdf.deriveData(HKDFParameterSpec.ofExtract().addIKM(key).extractOnly());
    byte[] info = "session-1".getBytes(StandardCharsets.UTF_8);
    var expand = HKDFParameterSpec.expandOnly(new SecretKeySpec(prk, "HKDF"), info, 32);
    byte[] okm = kdf.deriveData(expand);
    System.out.println("prk.len=" + prk.length + " okm.len=" + okm.length);
    System.out.println("repeatable=" + Arrays.equals(okm, kdf.deriveData(expand)));
  }
}
// 运行输出：
// prk.len=32 okm.len=32
// repeatable=true

✅ 实测（JDK 25）。要点：KDF.getInstance("HKDF-SHA256") 拿到标准 KDF；HKDF 两段式——extract（HKDFParameterSpec.ofExtract().addIKM(...).extractOnly() 得 PRK）与 expand（静态工厂 HKDFParameterSpec.expandOnly(SecretKeySpec, info, L) 喂给 deriveData）；同一参数派生结果确定（repeatable=true），密钥长度即请求的 L 字节。

25.5 PEM Encodings of Cryptographic Objects（JEP 470 · 第一次预览）

⚠️ 需 --enable-preview --release 25。

import java.security.KeyPairGenerator;
import java.security.PEMDecoder;
import java.security.PEMEncoder;
import java.security.PrivateKey;
public class PEM25b {
  public static void main(String[] a) throws Exception {
    var kp = KeyPairGenerator.getInstance("Ed25519").generateKeyPair();
    String pem = PEMEncoder.of().encodeToString(kp.getPrivate());
    System.out.println(pem.lines().findFirst().orElseThrow());
    PrivateKey back = PEMDecoder.of().decode(pem, PrivateKey.class);
    System.out.println("roundtrip=" + back.getAlgorithm());
  }
}
// 运行输出：
// -----BEGIN PRIVATE KEY-----
// roundtrip=EdDSA

✅ 实测（JDK 25 + 预览开关）。要点：java.security.PEMEncoder/PEMDecoder（of() 得线程安全可复用实例）把密钥 ⇄ PEM 文本一步转换，decode(text, Class) 免手工解析；本机 javap 核对 25 的 encode(DEREncodable) 参数类型（AsymmetricKey extends DEREncodable）。后续轮次：26（JEP 524 第二次预览：PEMRecord 改名 PEM、encryptKey 改 encrypt、支持 KeyPair/PKCS8EncodedKeySpec 加解密），27（JEP 538 第三次预览）——写法见 26.3 / 27.4。

25.6 Vector API（JEP 508 · 第十次孵化）

⚠️ 需 --add-modules jdk.incubator.vector（孵化模块，非 preview）。

import jdk.incubator.vector.IntVector;
import jdk.incubator.vector.VectorSpecies;
public class Vec25 {
  public static void main(String[] a) {
    VectorSpecies<Integer> SP = IntVector.SPECIES_256;
    int[] x = {1, 2, 3, 4, 5, 6, 7, 8};
    int[] y = {10, 20, 30, 40, 50, 60, 70, 80};
    int[] out = new int[8];
    var vx = IntVector.fromArray(SP, x, 0);
    var vy = IntVector.fromArray(SP, y, 0);
    vx.add(vy).intoArray(out, 0);
    System.out.println(java.util.Arrays.toString(out));
  }
}
// 运行输出：
// [11, 22, 33, 44, 55, 66, 77, 88]
