TermDefinition
MiddlewareA configurable layer that intercepts and customizes agent execution at specific points (hooks) in the agent loop.
Agent loopThe core cycle: call model → model chooses tools → execute tools → feed results back → repeat until no more tool calls.
HookA method/callback that runs at a specific point in agent execution (before/after model, before/after agent, around model/tool calls).
Node-style hookRuns sequentially at a fixed execution point: before_agent, before_model, after_model, after_agent.
Wrap-style hookRuns around each call, controlling whether the handler is called zero/one/many times: wrap_model_call, wrap_tool_call.
create_agentFactory function that compiles a LangGraph StateGraph with middleware wired in as nodes/edges.
AgentMiddlewareBase class; subclass it and implement hook methods to customize agent behavior.
AgentStateDefault state schema: messages (additive), jump_to (ephemeral), structured_response.
ModelRequestImmutable dataclass describing a model call (model, messages, system_message, tools, state, runtime). Use .override() to change it.
ModelResponseDataclass holding result (list of messages) and optional structured_response.
ExtendedModelResponseModelResponse + optional Command for injecting state updates from wrap_model_call.
ToolCallRequestDataclass describing a tool call (tool_call dict, tool, state, runtime).
jump_toState key that redirects execution to 'tools', 'model', or 'end'; requires can_jump_to declared on the hook.
can_jump_toHook configuration declaring which conditional edges (jump targets) the graph should build.
hook_configDecorator for class methods to configure hook behavior (currently can_jump_to).
ReducerA function that merges state updates (e.g. add_messages appends instead of replacing).
CommandLangGraph type for flow control / state injection (used in ExtendedModelResponse, wrap_tool_call).
CheckpointerPersists graph state across runs; required by HumanInTheLoopMiddleware and thread-level limits.
Thread limitMaximum calls across all runs sharing a thread_id (requires checkpointer).
Run limitMaximum calls within a single invocation (one user message → response).
Exponential backoffRetry delay initial_delay * (backoff_factor ** retry_number), capped by max_delay, with optional jitter.
PIIPersonally Identifiable Information.
Stream transformerScope-aware factory that projects live stream events onto typed channels.
Trace policyControls what middleware hook spans record (e.g. omit_payload).
dynamic_promptConvenience decorator wrapping wrap_model_call to generate the system prompt.
Deep AgentsA companion package (deepagents) providing FilesystemMiddleware, SubAgentMiddleware, RubricMiddleware.
