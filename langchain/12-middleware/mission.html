Why study this

Middleware is the mechanism that turns a naive "model → tool → model" loop into a production-grade agent. Everything you need to make agents reliable, safe, cost-controlled, and debuggable lives here: retries, fallbacks, summarization, PII redaction, human approval, call limits, and planning.

Success criteria

By the end of this course, you should be able to:

  1. Explain where middleware hooks run inside the agent loop, and why the two hook styles (node-style vs wrap-style) exist.
  2. Write custom middleware from memory, both decorator-based and class-based, including async variants.
  3. Draw the execution order for multiple middleware (before/after/wrap) and explain why after-hooks run in reverse.
  4. Explain the jump_to mechanism and how can_jump_to builds conditional edges in the compiled LangGraph.
  5. Read and reason about the built-in middleware source (retry, fallback, summarization, etc.).
  6. Answer "why this design / what trade-off / how would you improve" for each core concept.
  7. Pass a deep-grill interview on the topic without consulting notes.

Non-goals

  • You are not expected to memorize every config knob of all 20+ built-in middleware.
  • You are not expected to master deepagents package internals (Filesystem/Subagent/Rubric) beyond awareness level.

Source-level grounding

Every principle-level claim is backed by reading the installed langchain==1.3.14 source in venv/lib/python3.12/site-packages/langchain/agents/middleware/. When a claim cannot be traced to source, it is explicitly marked as documentation-derived.
