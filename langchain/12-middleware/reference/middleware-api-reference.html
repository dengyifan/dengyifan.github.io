This page is the complete API reference for langchain.agents.middleware, sourced from reference.langchain.com/python/langchain/middleware and cross-verified against the locally installed langchain==1.3.14 source. See the conceptual guides and lessons for usage examples.

Import path

All middleware, decorators, and types are importable from langchain.agents.middleware. Example: from langchain.agents.middleware import SummarizationMiddleware, before_model, AgentState.

Middleware Classes

LangChain provides 14 prebuilt middleware classes for common agent use cases, plus the base class for custom middleware.

SummarizationMiddleware

Summarizes conversation history when token limits are approached.

class SummarizationMiddleware(model, trigger=None, keep=("messages", 20), token_counter=None, summary_prompt=None, trim_tokens_to_summarize=4000)
ParameterTypeDefaultDescription
modelstr | BaseChatModelrequiredModel for generating summaries (identifier string or instance)
triggerContextSize | TriggerClause | list | NoneNoneCondition(s) for triggering summarization (single threshold = met; dict = AND; list = OR)
keepContextSize("messages", 20)How much context to preserve after summarization
token_counterfunctionNoneCustom token counting function (defaults to char-based)
summary_promptstrNoneCustom prompt template (must include {messages} placeholder)
trim_tokens_to_summarizenumber4000Max tokens to include when generating summary

HumanInTheLoopMiddleware

Pause agent execution for human approval, editing, or rejection of tool calls. Requires a checkpointer.

class HumanInTheLoopMiddleware(interrupt_on, description_prefix="Tool execution requires approval")
ParameterTypeDefaultDescription
interrupt_ondict[str, bool | InterruptOnConfig]requiredMapping of tool name → allowed actions. True = all decisions; False = auto-approve; config = specific decisions
description_prefixstr"Tool execution requires approval"Prefix used when constructing action requests
InterruptOnConfig fields

allowed_decisions (list of "approve"/"edit"/"reject"/"respond"), description (str or callable), args_schema (JSON schema for edits), when (predicate controlling whether to interrupt).

ModelCallLimitMiddleware

Tracks model call counts and enforces limits.

class ModelCallLimitMiddleware(thread_limit=None, run_limit=None, exit_behavior="end")
ParameterTypeDefaultDescription
thread_limitint | NoneNoneMax model calls across all runs in a thread
run_limitint | NoneNoneMax model calls per single invocation
exit_behavior"end" | "error""end""end" = graceful termination; "error" = raise ModelCallLimitExceededError

ToolCallLimitMiddleware

Track tool call counts and enforce limits during agent execution.

class ToolCallLimitMiddleware(tool_name=None, thread_limit=None, run_limit=None, exit_behavior="continue")
ParameterTypeDefaultDescription
tool_namestr | NoneNoneName of specific tool to limit (None = all tools)
thread_limitint | NoneNoneMax tool calls across a thread
run_limitint | NoneNoneMax tool calls per invocation
exit_behavior"continue" | "error" | "end""continue""continue" = block with error; "error" = raise; "end" = stop immediately

ToolRetryMiddleware

Automatically retries failed tool calls with configurable backoff.

class ToolRetryMiddleware(max_retries=2, tools=None, retry_on=(Exception,), on_failure="continue", backoff_factor=2.0, initial_delay=1.0, max_delay=60.0, jitter=True)
ParameterTypeDefaultDescription
max_retriesint2Max retry attempts after initial call
toolslist[BaseTool | str] | NoneNoneTools to apply retry to (None = all)
retry_ontuple | callable(Exception,)Exceptions to retry on
on_failure"continue" | "error" | callable"continue"Behavior when retries exhausted
backoff_factorfloat2.0Exponential backoff multiplier (0.0 = constant)
initial_delayfloat1.0Initial delay in seconds
max_delayfloat60.0Max delay cap
jitterboolTrueAdd ±25% random jitter

AgentMiddleware (Base Class)

Base middleware class for creating custom middleware. Subclass it and implement hook methods.

class AgentMiddleware(Generic[StateT, ContextT, ResponseT])

Class attributes declared on a subclass:

AttributePurpose
state_schemaExtend the agent state with custom fields
toolsRegister additional tools shipped with the middleware
transformersRegister scope-aware stream transformer factories

Hook methods (all optional; sync/async pairs):

MethodAsyncRuns
before_agentabefore_agentOnce, before agent starts
before_modelabefore_modelBefore each model call
after_modelaafter_modelAfter each model response
wrap_model_callawrap_model_callAround each model call
wrap_tool_callawrap_tool_callAround each tool call
after_agentaafter_agentOnce, after agent completes

Decorators

Create custom middleware using these decorators. Each returns an AgentMiddleware instance.

DecoratorHook TypeDescriptionSignature
@before_agentNode-styleExecute logic before agent execution startsfunc(state, runtime) -> dict | None
@before_modelNode-styleExecute logic before each model callfunc(state, runtime) -> dict | None
@after_modelNode-styleExecute logic after each model responsefunc(state, runtime) -> dict | None
@after_agentNode-styleExecute logic after agent execution completesfunc(state, runtime) -> dict | None
@wrap_model_callWrap-styleWrap and intercept model callsfunc(request, handler) -> ModelResponse
@wrap_tool_callWrap-styleWrap and intercept tool callsfunc(request, handler) -> ToolMessage | Command
@dynamic_promptConvenienceGenerate dynamic system prompts from request contextfunc(request) -> str | SystemMessage
@hook_configConfigConfigure hook behavior (e.g. can_jump_to)@hook_config(can_jump_to=[...])
Decorator parameters

Node-style decorators (before_agent, before_model, after_model, after_agent) accept state_schema, tools, can_jump_to, and name. Wrap-style decorators (wrap_model_call, wrap_tool_call) accept state_schema, tools, and name.

Types and Utilities

Core Types

TypeDescription
AgentStateState container for agent execution (fields: messages, jump_to, structured_response)
ModelRequestRequest details passed to model calls (model, messages, system_message, tools, state, runtime)
ModelResponseResponse details from model calls (result, structured_response)
ClearToolUsesEditUtility for clearing tool usage history from context
InterruptOnConfigConfiguration for human-in-the-loop interruptions

Summarization Types

Type / ConstantDescription
ContextSizeUnion type: ContextFraction | ContextTokens | ContextMessages
ContextFractionSummarize at fraction of total context (e.g. ("fraction", 0.8))
ContextTokensSummarize at token threshold (e.g. ("tokens", 4000))
ContextMessagesSummarize at message threshold (e.g. ("messages", 20))
