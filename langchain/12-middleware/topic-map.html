Cross-Links

  • Hooks depend on understanding the agent loop (model → tools → model).
  • Wrap-style hooks compose by nesting, which is why execution order matters.
  • Agent Jumps (jump_to) only work when the hook declares can_jump_to=[...] — this builds conditional edges in the compiled LangGraph.
  • Custom State Schema reuses the TypedDict + reducer model from LangGraph — same add_messages reducer semantics as AgentState.
  • Built-in middleware are themselves just AgentMiddleware subclasses — mastering custom middleware makes the built-ins readable.
  • This topic overlaps with LangGraph (StateGraph, checkpointer, Command) and Streaming (custom stream transformers, stream_mode="custom").
