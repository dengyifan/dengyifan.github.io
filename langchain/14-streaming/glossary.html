LangGraph Agent Streaming 术语表

LangGraph Agent 流式输出机制的核心概念定义。

stream_mode
LangGraph agent.stream() 方法的参数，决定流式输出的粒度。支持 updates、messages、custom、values、debug 五种模式，也支持列表形式的多模式组合。
Avoid: 流模式、输出模式
superstep
Agent 执行的一个完整步骤（如一次模型调用或一次工具调用）。每个 superstep 完成后触发一次 updates 模式的事件。是理解流式粒度的核心概念。
Avoid: 超级步骤、执行步
get_stream_writer()
LangGraph 提供的上下文函数，在工具函数内部调用，返回一个 writer 可调用对象，用于向 custom 流中写入自定义内容。基于 contextvars 实现线程安全。
Avoid: 流写入器、自定义输出器
content_blocks
AIMessageChunk 的属性，以列表形式存储消息内容块。每个元素可能是文本块（{"type": "text", "text": "..."}）或工具调用块（{"type": "tool_call_chunk", ...}）。在 messages 模式下逐 token 累积。
Avoid: 内容块、消息块
langgraph_node
messages 模式中 metadata 字典的键，值为当前 token 来源的节点名称（如 "model" 或 "tools"）。用于区分流式输出来自模型生成还是工具调用结果。
Avoid: 节点标识、来源节点
多模式组合
将 stream_mode 设为列表（如 ["updates", "custom"]），每次迭代返回 (stream_mode, chunk) 元组，根据第一个元素区分不同类型的流数据。
Avoid: 混合模式、复合流式
条件边（conditional edge）
LangGraph 中的一种边类型，由路由函数根据 state 动态决定下一步去向。在 Agent 中，条件边判断 messages[-1].tool_calls 是否非空，决定去 tools 节点还是结束。一条条件边包含多个分支，但只算一条边。
Avoid: 判断边、动态边
message_id（AIMessageChunk.id）
同一轮 LLM 生成拆出的所有 token 碎块（AIMessageChunk）共享的 id。用于流式拼接——id 变化说明一条新消息开始。是流式识别符，不持久化。
Avoid: 消息 id、token id
checkpoint
LangGraph 在每个 superstep 完成后保存的状态快照，可通过 thread_id 恢复。是状态恢复点，用于断点续传。与 message_id 职责不同（checkpoint 恢复状态，message_id 拼接流）。
Avoid: 检查点、存档点
handle_tool_errors
LangGraph 的工具异常处理参数。设为 True 时，工具抛出的异常被捕获并包装成 ToolMessage（含 tool_call_id 匹配）回传给 LLM，让 LLM 感知并处理失败，而非中断流程。
Avoid: 工具错误处理、异常捕获参数
writer 与 return 的职责分离
custom 模式中的核心设计原则。writer(...) 走"通知通道"（custom 流 → 用户），不进 messages、不被 LLM 看到；return 走"数据通道"（包装成 ToolMessage → messages → LLM）。是 CQRS 变体的体现。
Avoid: 写入器职责、流通道分离
消息边界（message boundary）
从 messages 模式的 token 碎块中判断一条消息何时结束。三种方式：message_id 变化（最可靠）、langgraph_node 节点切换、finish_reason 标记。
Avoid: 消息分隔、消息终止
静默失败（silent failure）
工具内 API 调用未抛异常但返回空字符串 "" 的场景。LLM 看到空 ToolMessage 是模糊信号，可能幻觉编造结果。应显式返回 "ERROR: ..." 让 LLM 明确知道是失败。
Avoid: 静默异常、空返回失败
ReAct 循环（ReAct loop）
Agent 的"推理-行动"循环：模型调用 → 决定调用工具 → 执行工具 → 结果回传模型 → 再次推理。一轮 ReAct 循环 = 一次 agent 节点 + 一次 tools 节点的完整流转。
Avoid: 反应循环、推理行动环
