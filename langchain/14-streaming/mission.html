Deep​Mastery / Streaming MISSION

Mission: 吃透 LangGraph Agent Streaming 的四种流式模式

Why

在实际开发中，Agent 的流式输出直接影响用户体验——从"等 5 秒出结果"到"打字机效果逐字显示"。LangGraph 提供了 4 种 stream_mode，每种有不同的粒度和适用场景。理解其底层机制——superstep 如何触发事件、get_stream_writer() 如何工作、多模式组合如何消费——是构建生产级 Agent 应用的基础能力。

Success looks like

  • 能解释 4 种 stream_mode（updates / messages / custom / values / debug）的区别和适用场景
  • 能独立编写所有 4 种模式的流式代码，并组合使用
  • 能画 Agent 执行流程中 stream 事件触发的时序图
  • 能理解 get_stream_writer() 的上下文机制和线程安全
  • 能解释 metadata["langgraph_node"] 的来源和作用
  • 能回答面试中关于流式输出的深度追问

Constraints

  • 基于 LangChain 1.0+ / LangGraph 0.2+ 生态
  • 学习时间：单次会话完成
  • 源码分析基于 LangGraph 开源仓库

Out of scope

  • LangGraph 底层图状态机的完整源码实现（StateGraph 内部细节）
  • 自定义 streaming 协议开发
  • 前后端流式传输协议（SSE / WebSocket 实现细节）
